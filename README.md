# Рейтинг Telegram-каналів та чатів 🇺🇦

Вітаємо! Цей проект створений для збору та систематизації найкращих українських спільнот у Telegram.

## 📋 Як потрапити в рейтинг?
Ви можете запропонувати канал, створивши [Issue](https://github.com/providnykzpun-bit/Rating/issues) або надіславши Pull Request.

## 🏆 Критерії оцінки
- Якість контенту.
- Відсутність спаму.
- Корисність для громади.
